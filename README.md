# basic-electronics


Navigation: a sidebar menu, a searchable home grid, back/next buttons and URL links to each topic (the ← and → keys also move between topics).

Interactive modules: Ohm's law, series/parallel resistors, voltage divider, capacitor (RC charging), inductor (RL), diode I-V curve, LED resistor, BJT switch, logic gates, AC sine wave, 555 timer, resistor color code and a reactance calculator.
Pop-up windows: the ⓘ chips and the clickable labels in the schematics (dashed underline) open an explanation window.
